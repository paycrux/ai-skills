## 2.3 선물내역 · 받은 선물 목록

### 목적
받은 선물을 한 화면에서 상태별로 확인하고, 상세로 이동할 수 있게 한다.

### 화면 구성
1. 상단 앱바: 페이지 이름 "선물하기", 오른쪽에 "모바일 상품권 등록" 버튼 → 상품권 등록 화면으로 이동
2. 탭: 기프트샵 / 선물내역 (이 문서는 선물내역 탭만 다룬다)
3. 칩: 받은 선물 / 보낸 선물. 기본값은 받은 선물
4. 조회기간: 최근 1달(기본) · 최근 3달. 누르면 기간 선택 시트
5. "사용 가능 상품권만 보기" 체크박스
6. 선물 카드 목록 (최신순)

### 선물 카드
- 첫 줄: "{보낸 사람 전화번호}님이 보낸 선물". 전화번호는 가운데 4자리 마스킹
- 둘째 줄: 상품명
- 사용 가능한 선물에는 안내 문구: "받은 선물은 자동으로 모바일 상품권에 등록됐어요."
- 받은 일시: YYYY.MM.DD HH:mm
- 오른쪽 "상세보기" 버튼 → 선물 상세
- 사용완료 · 기간만료 · 환불된 선물은 회색으로 표시하고 첫 줄 앞에 [사용완료] · [기간만료] · [환불] 을 붙인다

### 정책
- 한 번에 20개씩 불러오고, 끝까지 스크롤하면 다음 20개를 불러온다
- 조회기간을 바꾸면 목록을 처음부터 다시 불러온다

### 미정
- (기획 확인 중) 받은 선물이 하나도 없을 때의 화면
