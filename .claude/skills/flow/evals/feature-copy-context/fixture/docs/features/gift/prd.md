# 선물하기

## 1-1 기프트샵

- 선물할 상품을 고르는 화면.
- 상품이 하나도 없으면 목록 자리에 "아직 선물할 수 있는 상품이 없어요." 를 보여 준다.
- 한 번에 담을 수 있는 선물은 최대 5개. 6개째를 담으려 하면 스낵바 "선물은 한 번에 최대 N개까지 보낼 수 있어요." (N은 최대 개수)

## 1-2 선물 결제

- 받는 사람 · 메시지 입력 후 결제.
- 메시지를 입력한 상태에서 [취소] 또는 뒤로가기를 누르면 확인 모달.
  - 1줄: "작성 중인 메시지가 있어요."
  - 2줄: "나가면 입력한 내용이 사라져요."
  - 버튼: [취소] [나가기]
- 결제가 실패하면 스낵바 "결제에 실패했어요. 다시 시도해 주세요."
- 메시지 입력칸 placeholder: "마음을 담아 메시지를 적어 주세요"

## 1-3 보낸 선물함

- 보낸 선물 목록. 목록이 비면 "아직 보낸 선물이 없어요."
- 선물함에서 [다시 보내기]로 결제하다 실패하면 1-2와 동일한 문구를 띄운다.
