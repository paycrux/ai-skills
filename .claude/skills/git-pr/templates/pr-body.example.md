# 문장 톤 참고용 샘플

실제 PR body가 아니라 서술 방식만 보기 위한 예시다. 다이어그램은 여기에 넣지 않는다 — 형태 선택은 `mermaid-forms.md`가 담당하고, 대부분의 그룹은 다이어그램 없이 불릿만으로 끝나는 것이 정상이다.

## 변경사항

### 상품 등록

- 상품 등록 폼 신규 — 카테고리·가격·재고 입력, 제출 시 목록 캐시 무효화
- 카테고리 옵션을 서버 enum 응답에서 로드 (기존 하드코딩 배열 제거)

#### 카테고리를 서버에서 받는 이유

신규 카테고리 추가 시 클라이언트 배포 없이 반영하기 위함. 대신 초기 로딩에 요청 1회가 추가됨.

### 상품 목록 페이지네이션

- offset 방식 → cursor 방식 전환
- 스크롤 복원을 위해 커서를 URL 쿼리에 유지
