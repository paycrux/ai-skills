# Frontend Design Rules (디자인 레퍼런스 없을 때)

> 디자인 소스(Figma, 스크린샷, 디자인 스펙)가 없을 때만 적용.
> 디자인이 있으면 이 파일을 무시하고 제공된 디자인을 정확히 따를 것.

## AI Slop 방지

다음은 AI가 기본적으로 수렴하는 클리셰 — 반드시 피할 것:

- **폰트**: Inter, Roboto를 무조건 사용하지 말 것. 프로젝트 맥락에 맞는 폰트 선택.
- **색상**: 흰 배경 + 퍼플/블루 그라디언트 조합 금지. 목적과 브랜드에 맞는 색상 선택.
- **레이아웃**: 모든 페이지를 동일한 카드 그리드로 만들지 말 것.
- **아이콘**: 의미 없는 장식용 아이콘 남발 금지.

## 맥락 기반 선택

UI를 직접 디자인해야 할 때:

1. **프로젝트 기존 스타일 우선** — 이미 사용 중인 폰트, 색상, 간격 체계가 있으면 그걸 따름
2. **도메인에 맞는 톤** — 금융 앱이면 보수적, 크리에이티브 도구면 대담하게
3. **라이트/다크 모드** — 프로젝트에 다크 모드가 있으면 반드시 대응
4. **접근성** — 색상 대비 4.5:1 이상, 포커스 가시성 확보
